# Cassandra Query Studio

An interactive **Cassandra query execution and visualization platform** built with **Python and Streamlit**.
Execute Cassandra queries through a user-friendly UI and instantly visualize keyspaces, tables, and records.
Supports core operations including **CREATE, INSERT, SELECT, UPDATE, DELETE, and DROP**.
Designed to provide a practical, visual alternative to terminal-based Cassandra query execution.
Ideal for exploring Cassandra database operations through an interactive workflow.

**Tech Stack:** Python • Streamlit • Apache Cassandra
